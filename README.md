# ai-proofs

Isabelle/HOL formalizations developed using AI assistance.

1. [Pascal's Hexagon Theorem](pascal_thm_project/Pascal_Hexagon/) — completed.
2. [Kőnig's Edge Colouring Theorem](koenig_thm_project/Koenig_Edge_Colouring/) — completed.
3. [Four Colour Theorem](four_colour_thm_project/Four_Colour/) — the finite combinatorial hypermap formulation is proved (at least according to AI), now just awaiting the final statement. The project is still in a draft stage - that is, I haven't read over any content (any text or code) whatsoever AI has put there yet and thus can't say any of it is correct yet.
